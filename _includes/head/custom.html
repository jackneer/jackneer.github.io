{% comment %} Mermaid diagrams via CDN — client-side only, no Jekyll plugin needed. Usage in any Markdown page: ```mermaid graph LR A[Draft] --> B[main] B --> C[Deploy] ``` kramdown turns that fence into 
,
  while Mermaid only renders 
 elements. This script:

    1. Checks whether the page has a  block.
    2. If yes, dynamically loads the Mermaid UMD bundle from the CDN.
    3. Transforms code blocks into .mermaid divs.
    4. Calls mermaid.run() to render.

  Both the transform and mermaid.run() are wrapped in try/catch so that
  a failure in one diagram never breaks the rest of the page.
